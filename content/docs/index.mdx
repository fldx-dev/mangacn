---
title: Introduction
description: Manga-styled React components, distributed as a shadcn registry.
---

mangacn is a set of React components drawn like a manga page: ink outlines, screentone,
speech bubbles, panels and sound effects. Every item is a shadcn registry item, so the code
lands in your project and stays yours to edit.

Install the theme and the two fonts first, then the ink frame that the drawn components share,
then any item:

```bash
npx shadcn@latest add @mangacn/theme @mangacn/font-display @mangacn/font-dialogue
npx shadcn@latest add @mangacn/ink-frame
npx shadcn@latest add @mangacn/speech-bubble
```

Every item and its demos are on show in the [gallery](/demo).
