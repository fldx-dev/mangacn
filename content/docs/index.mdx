mangacn is a set of React components drawn like a manga page: ink outlines, screentone,
speech bubbles, panels and sound effects. Every item is a shadcn registry item, so the code
lands in your project and stays yours to edit.

Install the theme and its three fonts:

<InstallCommand item="theme" />

Then any item. The drawn ones bring the ink frame that outlines them in the same command:

<InstallCommand item="speech-bubble" />

<CopyPrompt item="speech-bubble" />

And use it:

```tsx
import { SpeechBubble } from "@/components/speech-bubble";

// The tail points at whoever is speaking.
export function Line() {
  return <SpeechBubble aria-label="Kenji">Wait… you're the new hero?!</SpeechBubble>;
}
```

Every item and its demos are on show in the [gallery](/demo).

## What is mangacn?

mangacn is a free, open-source (MIT) library of manga-styled React components for shadcn/ui.
It restyles shadcn's primitives (button, dialog, tabs, select and the rest) as hand-inked
outlines on paper, and adds manga-native pieces: speech bubbles, comic panels, screentone
backgrounds, sound-effect lettering, speed lines and page-turn motion, plus blocks such as a
chapter list, a manga reader and a chat thread. It installs with the shadcn CLI, so every file
is plain source in your project.

What it is made of:

- **More than 80 components and 11 blocks**, listed on [Components](/docs/components) and
  [Blocks](/docs/blocks).
- **One theme:** ink on paper, four screentone greys and a single spot colour, as CSS variables
  and Tailwind v4 utilities, with dark mode and three [presets](/docs/theming#presets).
- **One pen:** the ink frame, which draws every outline with rough.js.
- **Agent support:** a docs MCP server, an Agent Skill and the whole docs as Markdown at
  [/llms.txt](/llms.txt). See [Agents](/docs/agents).

How it differs from stock shadcn/ui is on [mangacn vs. shadcn/ui](/docs/shadcn), and the
questions people ask before installing are answered in the [FAQ](/#faq).
