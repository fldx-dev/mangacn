Stock's table-of-contents page in ink, with stock's two files and exports: a handbook page with a sidebar on the right listing every section with its pages beneath it, beside a chapter's blank [panels](/docs/components/panel). Mangacn's [Sidebar](/docs/components/sidebar) slides away with <kbd>Ctrl</kbd>+<kbd>B</kbd> (<kbd>⌘</kbd>+<kbd>B</kbd> on a Mac) or the trigger, which is turned to face it, and opens as a sheet on phones; it is an alternative to the other sidebar blocks, which write the same `app/dashboard/page.tsx` and `components/app-sidebar.tsx`, so adding one replaces the other.

Neither file is a client component, as in stock's block: the page and `app-sidebar.tsx` are server components, and the sidebar primitive they render holds the state.
