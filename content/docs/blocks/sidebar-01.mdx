Stock's documentation shell in ink, with stock's four files and exports: an edition menu and a search field over the sections, each a labelled group of links, beside a chapter's blank [panels](/docs/components/panel). Mangacn's [Sidebar](/docs/components/sidebar) slides away with <kbd>Ctrl</kbd>+<kbd>B</kbd> (<kbd>⌘</kbd>+<kbd>B</kbd> on a Mac) or the trigger and opens as a sheet on phones; it is an alternative to the other sidebar blocks, which write the same `app/dashboard/page.tsx` and `components/app-sidebar.tsx`, so adding one replaces the other.

The page and `app-sidebar.tsx` are server components, as in stock's block; `search-form.tsx` and `version-switcher.tsx` are client components.
