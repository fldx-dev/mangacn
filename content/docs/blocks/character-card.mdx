A cast entry for a series page: the character's portrait, name and reading, role, a line they say and their stats, on one card. Use one per character on a cast page, and link each to the character's own page with `href`.

It is a server component that composes card, manga-frame, caption-box, speech-bubble, power-gauge and stamp and draws nothing of its own. The portrait sits in a 3:4 manga-frame with the `status` word stamped on its top corner; the name is in the display face, with `reading` set as ruby over it under `lang="ja"`; the role is in a caption box, the quote in a speech bubble whose tail points back at the speaker, and each stat is a segmented power gauge. The card is a container: wider than 24 rem it puts the portrait beside the text, narrower it stacks them, whatever the viewport.

The card is an `article` named by `name` (the reading is not part of the name). The stats are a description list whose values are text ("80 of 100"), so they never rest on the gauges, which draw the same label and value for the eye and are hidden from assistive technology. With `href` the name is one link whose hit area covers the card, and the card shows a focus ring when it is focused. The `role` prop is the character's part in the story, not an ARIA role: the card is always an article.
