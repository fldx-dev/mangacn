Stock's email-only sign-up in ink, with stock's two files and exports: the studio's mark drawn in the current ink colour above the title in the display face, one email field, and Apple and Google with stock's marks in ink beside their labels. Both files are server components (stock's form is a client component only for its icon placeholder); it is an alternative to the other sign-up blocks, which write the same `app/signup/page.tsx` and `components/signup-form.tsx`, so adding one replaces the other.
