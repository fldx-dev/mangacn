Stock's email-only sign-up in ink, with stock's two files and exports: the studio's mark drawn in the current ink colour above the title in the display face, one email field, and Apple and Google with stock's marks in ink beside their labels. Both files are server components (stock's form is a client component only for its icon placeholder); it is an alternative to the other sign-up blocks, which write the same `components/signup-form.tsx`, so adding one replaces the other.

## Props

`SignupForm` takes its root `div`'s props. Every field submits under its `id` as its `name` (`email`). The copy is props too, each defaulting to what the preview shows: `title` (the heading, which names the form), `providers` (the other providers' buttons), and `footer`, the sign-in line ("Already have an account?" and a link to `/login`), under the heading. `providers` takes nodes, so pass your own buttons wired to your sign-in calls (a client component of yours, since the page is a server component), or `null` for none, which also drops the "Or" rule.
