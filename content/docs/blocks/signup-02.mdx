Stock's split-screen sign-up page in ink, with stock's two files and exports: the studio's mark and the form on the left, the title in the display face and stock's GitHub mark in the current ink colour, and on the right, where stock shows a placeholder photo, a manga panel the items draw: a [halftone background](/docs/components/halftone-background), [focus lines](/docs/components/focus-lines) and one [sound effect](/docs/components/sfx-text) in a heavy [manga frame](/docs/components/manga-frame), hidden from screen readers and shown from the `lg` breakpoint up. Both files are server components; it is an alternative to the other sign-up blocks, which write the same `app/signup/page.tsx` and `components/signup-form.tsx`, so adding one replaces the other.
