Stock's calendar shell in ink, with stock's five files and exports: mangacn's [Sidebar](/docs/components/sidebar) holds the editor's account menu, a [Calendar](/docs/components/calendar) and the studio's collapsible calendars, slides away with <kbd>Ctrl</kbd>+<kbd>B</kbd> (<kbd>⌘</kbd>+<kbd>B</kbd> on a Mac) or the trigger and opens as a sheet on phones, beside a month of blank [panels](/docs/components/panel); the sample month is fixed so the page looks the same every day (`date-picker.tsx` says how to make it live). It is an alternative to [Sidebar 07](/docs/blocks/sidebar-07): both write `app/dashboard/page.tsx`, `app-sidebar` and `nav-user`, so adding one replaces those files of the other.

The page is a server component; `app-sidebar`, `calendars` and `nav-user` are client components, and `date-picker` has no directive, as in stock: it holds state, so import it only from a client component, as `app-sidebar` does.
