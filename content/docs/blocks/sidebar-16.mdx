Stock's shell under a site header, in ink, with stock's eight files and exports: the header is the page's one banner and stays above mangacn's [Sidebar](/docs/components/sidebar) while the page scrolls, with a named toggle (or <kbd>Ctrl</kbd>+<kbd>B</kbd>, <kbd>⌘</kbd>+<kbd>B</kbd> on a Mac) that slides the sidebar away and opens it as a sheet on phones, beside a chapter's blank [panels](/docs/components/panel); swap the studio's sample data in `app-sidebar.tsx` for your own. It is an alternative to the other sidebar blocks: it writes `app/dashboard/page.tsx` and component files of the same names, so adding it replaces theirs.

The page is a server component and the seven component files are client components, as in stock's block.
