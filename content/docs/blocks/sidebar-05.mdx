Stock's documentation shell in ink, with stock's three files and exports: the handbook's mark and a search field over the sections, each a [collapsible](/docs/components/collapsible) button that opens and closes its pages, beside a chapter's blank [panels](/docs/components/panel). Mangacn's [Sidebar](/docs/components/sidebar) slides away with <kbd>Ctrl</kbd>+<kbd>B</kbd> (<kbd>⌘</kbd>+<kbd>B</kbd> on a Mac) or the trigger and opens as a sheet on phones; it is an alternative to the other sidebar blocks, which write the same `app/dashboard/page.tsx` and `components/app-sidebar.tsx`, so adding one replaces the other.

The page is a server component and `app-sidebar.tsx` and `search-form.tsx` are client components, as in stock's block.
