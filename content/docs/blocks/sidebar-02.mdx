Stock's documentation shell in ink, with stock's four files and exports: an edition menu and a search field over the sections, each a [collapsible](/docs/components/collapsible) group whose label opens and closes its links, beside a sticky header and a storyboard of blank [panels](/docs/components/panel). Mangacn's [Sidebar](/docs/components/sidebar) slides away with <kbd>Ctrl</kbd>+<kbd>B</kbd> (<kbd>⌘</kbd>+<kbd>B</kbd> on a Mac) or the trigger and opens as a sheet on phones; it is an alternative to the other sidebar blocks, which write the same `app/dashboard/page.tsx` and `components/app-sidebar.tsx`, so adding one replaces the other.

The page is a server component and the three sidebar files are client components, as in stock's block.
