Stock's documentation shell in ink, with stock's two files and exports: the handbook's mark over every section, each a link with its pages beneath it on the submenu's ink guide rule, beside a chapter's blank [panels](/docs/components/panel). Mangacn's [Sidebar](/docs/components/sidebar) slides away with <kbd>Ctrl</kbd>+<kbd>B</kbd> (<kbd>⌘</kbd>+<kbd>B</kbd> on a Mac) or the trigger and opens as a sheet on phones; it is an alternative to the other sidebar blocks, which write the same `app/dashboard/page.tsx` and `components/app-sidebar.tsx`, so adding one replaces the other.

The page is a server component and `app-sidebar.tsx` is a client component, as in stock's block.
