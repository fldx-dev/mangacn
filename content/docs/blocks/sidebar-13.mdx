Stock's settings dialog with a sidebar inside, in ink, with stock's two files and exports: one add writes `app/dashboard/page.tsx` and `components/settings-dialog.tsx`, where shadcn's sidebar-13 puts them. The page's button opens a mangacn [Dialog](/docs/components/dialog) that holds focus until it closes; in it a [Sidebar](/docs/components/sidebar) that does not collapse, a navigation landmark named "Settings sections", lists a manga reader's settings from the `md` breakpoint up, as stock's does, beside the open section's blank [panels](/docs/components/panel). The page stays one `main` with an `h1`: the dialog's content column is a `div` where stock nests a second `main`, and the dialog opens from the button rather than on load. It writes the same route as the other sidebar blocks, so adding it replaces their page.

The page is a server component and `settings-dialog.tsx` is a client component, as in stock's block.
