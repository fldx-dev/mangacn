A text field that filters a long list as the reader types, such as a series picker or a genre filter: the field is Input Group's one hand-drawn outline, and the list is Dropdown Menu's heavy-outlined paper with the highlighted row in ink. In multiple mode each pick becomes an outlined paper chip inside the field, and the arrow keys, typing and Escape work as in stock.

The examples open their list on load and run in their own stage, so the open list does not cover this page.
