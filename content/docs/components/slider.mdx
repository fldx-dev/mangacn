A hand-drawn rule with an ink range and paper thumbs, for a value picked on a scale: screentone density, a page range to export. Pass `value` or `defaultValue` as an array (one entry per thumb), and name the slider with `aria-labelledby` pointing at its visible label, which Base UI hands to every thumb; the theming page's pen controls are built from it.
