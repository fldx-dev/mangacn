Put it beside anything a reader will paste somewhere else: an install command, a share link, an API key. It is mangacn's Button, icon-only by default, and confirms with a check for two seconds; Code Block keeps its own copy button.

It follows the WAI-ARIA Button pattern: a native `button` whose name follows its state ("Copy", then "Copied" or "Copy failed"), announced once in a polite live region.

- Enter or Space: copies the value.
