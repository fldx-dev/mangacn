A stat bar from a character sheet: the label in the display face, the value as text beside it, and an ink fill on a hand-drawn rule that ends in a heavy tick. Pass `segments` for blocks with paper gaps (whole blocks fill), `color="spot"` for the one stat that matters, and `burst` for a tilted "MAX" once the bar is full. It is a `meter` named by its visible label, so a stack of gauges inside a Card reads as Power, Speed, Ink with their values; use Progress instead for a task that is still running.
