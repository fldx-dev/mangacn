A stat bar from a character sheet: the label in the display face, the value beside it and an ink fill on a hand-drawn rule, split into blocks with `segments`, in spot for the stat that matters, with a tilted "MAX" `burst` when full. It is a `meter` named by its label, so a stack of gauges in a Card reads as Power, Speed, Ink; use Progress for a task still running.
