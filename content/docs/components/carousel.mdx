A row of slides the reader steps through with the arrow buttons, the arrow keys or a swipe, for a run of panels, covers or quotes. The viewport draws nothing, so each slide brings its own frame (a `manga-frame`, a `card`); previous and next are mangacn's outlined icon buttons.

## Examples

Five numbered pages, one at a time. Each slide pads its frame a little, because the viewport clips whatever the pen draws past the slide's box.
