A file, a diff or a command set the way these docs set code: a heavy ink outline, a mono title over a hand-drawn rule, numbered lines and an outlined copy button. Pass it highlighted lines, from `await highlightCode(code, lang)` on the server or `useHighlightedCode(code, lang)` for code that streams; both come from stock's `use-highlighted-code` hook, which installs with it unchanged (GitHub's colours, set in `lib/highlighter.tsx`), while the examples here use the docs' ink themes.
