A file, a diff or a command set the way these docs set code: a heavy ink outline, a mono title over a hand-drawn rule, numbered lines and an outlined copy button. Pass it highlighted lines from stock's `use-highlighted-code`, which installs with it unchanged: `await highlightCode(code, lang)` from `lib/highlighter.tsx` on the server, or `useHighlightedCode(code, lang)` for code that streams.

The stock highlighter colours tokens with GitHub's light and dark themes, set in `lib/highlighter.tsx`; the examples here use the docs' own ink themes instead.
