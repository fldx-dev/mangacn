A file in a chat or a composer, drawn as a paper card in a hand-drawn outline, with its preview in a thinner ink frame and its actions as mangacn's icon [Button](/docs/components/button). The `state` shows where the file is: dashed while `idle`, a pulsing preview while `uploading` or `processing`, and an outline in spot on `error`.
