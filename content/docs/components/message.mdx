The layout around a chat message: an avatar slot, a name in the display face, the content and a muted footer for the time or read state, mirrored with `align="end"`. It draws nothing itself; put mangacn's [Avatar](/docs/components/avatar) in the avatar slot and [Bubble](/docs/components/bubble)s in the content.
