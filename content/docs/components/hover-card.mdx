A preview that opens when a pointer rests on a link, such as an author's card beside a byline, drawn as a speech bubble's round-cornered paper panel without the tail. Keep the trigger a real link to the full page: touch screens never hover, so the card is a shortcut, not the only way there. The examples run in their own stage, so the open card does not cover this page.
