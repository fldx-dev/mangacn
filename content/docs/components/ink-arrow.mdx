A hand-drawn arrow pointing at the next chapter, the button to press first or a detail in a panel; pair it with Ink Mark to annotate a sentence and its call to action alike. Without a `label` it is decoration hidden from assistive tech, so the target must name itself; with one, the text sits at the tail and the arrow is an image named by it.
