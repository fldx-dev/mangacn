A row of content with optional media, a display-face title, a description and actions, such as a chapter in a list or a settings entry. `variant="outline"` makes it a paper card in a heavy outline, `muted` sets it on tone-1; in an `ItemGroup`, give each item `role="listitem"` and divide them with `ItemSeparator`'s hand-drawn rule, `aria-hidden` there since a list holds only items.
