A row of content with optional media, a display-face title, a description and actions, such as a chapter in a list or a settings entry. `variant="outline"` makes it a paper card in a heavy outline, and `muted` sets it on tone-1.

## Examples

An outlined row with a title, a description and a Read action.

An `ItemGroup` is a list: give each item `role="listitem"` and divide them with `ItemSeparator`'s hand-drawn rule, marked `aria-hidden` here because a list holds only list items. The other way is to put the separator inside the list item, as [Chapter List](/docs/blocks/chapter-list) does, so the list holds only list items and nothing needs `aria-hidden`.
