An input or textarea with text, icons or buttons attached, such as a URL prefix, a result count or a send button, drawn as one outline with an inked rule between each addon and the control. Use mangacn's `input`, `textarea` and `button` inside it: they draw no frame of their own in a group, and the group takes the focus ring; name the control with a label or `aria-label`.
