A field for a short one-time code, a PIN or a verification number, typed into a row of paper slots: the active slot is traced at the heavy width with an ink caret, and groups are parted by a hand-drawn dash. Put it in a `field` with a label, pass `pattern` (`REGEXP_ONLY_DIGITS` from `input-otp`) to limit what it takes, and set `aria-invalid` to ink every slot in the spot colour.
