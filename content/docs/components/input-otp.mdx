A row of paper slots for a one-time code, a PIN or a verification number: the active slot is traced at the heavy width with an ink caret, and groups are parted by a hand-drawn dash. Name it with a label (or `aria-label`), limit what it takes with `pattern` (`REGEXP_ONLY_DIGITS` from `input-otp`), and set `aria-invalid` to ink every slot in the spot colour.

## Examples
