A box that keeps its content at a ratio as its width changes: a cover image, a video, a panel sketch. It draws nothing itself, so frame the content inside it (a `panel`, an `ink-frame`) when it needs an outline.

## Examples

A 16:9 box filled with a toned `ink-frame`, which keeps the ratio as the column narrows.
