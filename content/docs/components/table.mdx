Rows of data between hand-drawn rules, with a heavy rule under the header: a release schedule, a page count per chapter. Keep it for real tabular data; a list of cards suits anything else. Unlike stock, the scroll container around the table is a named region in the tab order, so a keyboard can scroll a wide table; name it with `label` when a page has more than one.
