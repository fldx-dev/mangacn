A native `<select>` drawn like `select`'s trigger: the paper box, the hand-drawn outline and the chevron, with the browser's own option list. Use it where the platform picker matters (phones, long lists, forms without script); use `select` for a styled popup.

## Examples

A disabled placeholder option and an option group, in the browser's own list.

The default beside `size="sm"`, `disabled` and `aria-invalid`.

<DemoFrame item="native-select" demo="states" />

In a form, put it in a `field` with a `FieldLabel` whose `htmlFor` names the select's `id`, and point `aria-describedby` at the description.
