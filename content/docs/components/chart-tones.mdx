Screentone fills for data: render `<ChartTones />` once on the page and any SVG shape takes `fill="url(#tone-dots-2)"`, so series are told apart by tone density instead of hue. The ids are plain exported strings (`CHART_TONE_IDS`, `chartToneFill`), so a server page or a Chart config can name them; the patterns draw in the text colour where `<ChartTones />` sits, and `prefix` defines a second set in another colour.
