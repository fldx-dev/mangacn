Screentone fills for data, so series are told apart by tone instead of hue: render `<ChartTones />` once on the page and any SVG shape takes `fill="url(#tone-dots-2)"`. The patterns draw in the text colour where `<ChartTones />` sits, and `prefix` defines a second set in another colour.

The ids are plain exported strings (`CHART_TONE_IDS`, and `chartToneFill(tone, prefix)` for the `url(…)`), so a server page or a [Chart](/docs/components/chart) config can name them without a client boundary.
