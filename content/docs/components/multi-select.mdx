Pick several values from a known list, such as a series' genres or a reader's tags: pass an options array and read string values back, with one hidden input per value for a plain form. Pair it with Field for a label and a hint; for custom rows or chips, compose [Combobox](/docs/components/combobox)'s parts instead.

It follows the WAI-ARIA Combobox pattern with a multi-select listbox popup:

- Type to filter the list.
- Down and Up move the ink highlight.
- Enter picks or unpicks the highlighted option.
- Backspace in the empty input removes the last chip.
- Escape closes the list.
